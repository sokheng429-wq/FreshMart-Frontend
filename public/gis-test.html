What the messages mean

  • SUCCESS — got an ID token… → the flow works end-to-end in the browser; the backend will verify this token and log you in.
  • origin_mismatch / "Access blocked" → http://localhost:5173 is missing from the client's Authorized JavaScript origins (or propagation hasn't finished — wait a few minutes).
  • invalid_client → the client id here doesn't exist in the selected project, or the client type is not Web application.
  • Google hasn't verified this app → the consent screen is Testing/Unverified; add yourself as a test user or click Continue in the popup.
  • script load failure → network can't reach accounts.google.com.
